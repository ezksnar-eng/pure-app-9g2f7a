# صفحة — متصفح Android بكوتلن

مشروع Android Studio أصلي، بواجهة Kotlin و`WebView` داخلي. لا يستخدم خادمًا أو حسابًا خاصًا بالتطبيق.

## الوظائف

- بحث العبارات عبر Google، وفتح Google وPinterest ومواقع HTTP/HTTPS داخل `WebView` نفسه.
- شريط عنوان وأزرار رجوع/تقدم/تحديث/رئيسية ومفضلة وسجل.
- حفظ السجل والمفضلة في `SharedPreferences` محليًا على الجهاز.
- ملفات تعريف الارتباط وبيانات `localStorage` للمواقع تحفظها Android WebView محليًا.
- خيار لمسح ملفات الارتباط وبيانات المواقع وذاكرة التخزين المؤقت.
- منع تجاوز أخطاء شهادات HTTPS، ومنع مخططات الروابط غير الآمنة مثل `javascript:` و`file:`.

## البناء إلى APK

1. فك ضغط المشروع وافتح مجلد `browser-kotlin` في Android Studio كـ **Existing Project**.
2. ثبّت Android SDK Platform 35 عند طلبه، واستخدم JDK 17 أو ما يرفقه Android Studio.
3. انتظر Gradle Sync، ثم اختر **Build > Build APK(s)**.
4. ملف APK التجريبي يظهر عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

قد تختلف أسماء عناصر القوائم قليلًا حسب إصدار Android Studio. قبل نشر التطبيق على متجر، حدّث إصدارات Gradle/Android Gradle Plugin وSDK وفق المتطلبات السارية حينها، واختبره على الأجهزة المستهدفة.

## تنبيهات

- Google قد يمنع تسجيل الدخول لبعض التطبيقات التي تفتح صفحة تسجيل الدخول داخل WebView؛ لا يغيّر المشروع هوية المتصفح للتحايل على هذا القيد.
- بعض المواقع قد تعرض تجربة مختلفة أو تمنع بعض ميزاتها داخل WebView. تُفتح صفحات الويب داخل التطبيق، لكن سلوكها تحدده المواقع نفسها.
- تعطيل ملفات الطرف الثالث افتراضيًا يحسن الخصوصية، لكنه قد يؤثر على بعض عمليات تسجيل الدخول أو التضمين.
- هذا متصفح يعتمد على WebView ونظام Android، وليس محرك بحث مستقلًا ولا يملك فهرس نتائج خاصًا؛ البحث يستخدم Google.
- الكوكيز وبيانات المواقع تُحفظ محليًا عبر Android WebView، وليست جزءًا من سجل/مفضلة التطبيق.
